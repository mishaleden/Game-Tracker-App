# Game Tracker

A personal video game tracker for Android (designed for the Galaxy Z Fold 6).
Search games, sort them into lists (Playing, Completed, Backlog, Wishlist, Dropped,
Favourites), and keep everything stored on your phone — no account needed.

## Try it on your phone
1. Install **Expo Go** from the Play Store.
2. On a computer with Node.js: `npm install` then `npx expo start`.
3. Scan the QR code with Expo Go.
4. In the app, open **Settings** and paste your IGDB Client ID and Secret
   (free — see https://api-docs.igdb.com/#account-creation).
